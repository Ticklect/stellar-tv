# Screenshot contributions

Place genuine project screenshots in this directory and reference them from the root README.

For each screenshot:

- Use a descriptive lowercase filename, such as `ue50u8000-home-focus.jpg`.
- State the TV model, Tizen version if known, TizenBrew version, and module version in the pull request.
- Crop or redact account details, local network addresses, device identifiers, cookies, signed media URLs, and viewing history.
- Capture only what is needed to demonstrate this module's navigation or player behavior.
- Do not add mockups as evidence, copyrighted promotional artwork, or third-party logos as repository branding.
- Confirm that you have permission to contribute the image under the repository license or document its separate license.

No screenshot is currently included because no reviewed, redistributable device capture is available.
